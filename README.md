# Demolab Creativity

A static website for Demolab Creativity, a handmade craft brand (phone cases, charms, and DIY material packs) I started, originally to apply for a market stall. The brand has since wound down, but the site remains as a design exercise.

## About

Followed a YouTube tutorial to learn the site structure, then customized the content, images, and UI (including the button design) to build out my own brand identity.

## Pages

Home, Founder, Gallery, Story, Contact

## Stack

HTML/CSS, static pages only.
